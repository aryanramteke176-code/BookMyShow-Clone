# BookMyShow Clone

A full-stack movie ticket booking application inspired by BookMyShow, built using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

* User Registration & Login
* Movie Browsing and Search
* Theatre & Screen Management
* Show Scheduling
* Seat Selection and Booking
* Booking Cancellation
* My Bookings Dashboard
* Admin Panel

## Tech Stack

### Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL

### Frontend

* HTML
* CSS
* JavaScript

## How to Run

### Backend

1. Open the project in IntelliJ IDEA.
2. Configure MySQL and update database credentials in `application.properties`.
3. Start MySQL Server.
4. Run:

```bash
BookMyShowApplication.java
```

or start the Spring Boot application from IntelliJ.

5. Backend will run on:

```text
http://localhost:8080
```

### Frontend

Open the `UI` folder.

**Start from:**

```text
homepage.html
```

This is the main entry page of the application.
